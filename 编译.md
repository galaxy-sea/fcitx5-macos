
## **一、首次完整编译**

```
git switch --no-recurse-submodules custom/macos && \
git pull --ff-only --no-recurse-submodules origin custom/macos && \
git -C fcitx5-webview switch custom/macos && \
git -C fcitx5-webview pull --ff-only --no-recurse-submodules origin custom/macos && \
git submodule update --init --recursive -- \
    fcitx5 \
    fcitx5-beast \
    deps/AlertToast \
    deps/url-filter && \
git -C fcitx5-webview submodule update --init --recursive && \
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer && \
brew install cmake ninja extra-cmake-modules gettext librsvg qpdf pkgconf && \
./scripts/install-deps.sh && \
pnpm --prefix=fcitx5-webview install && \
./scripts/patch.sh && \
cmake -B build/$(uname -m) -G Ninja \
    -DCMAKE_BUILD_TYPE=Release \
    -DBUILD_PREVIEW=OFF \
    -DKEY_LOGGING=OFF && \
cmake --build build/$(uname -m) --parallel 8 && \
sudo cmake --install build/$(uname -m) && \
./scripts/code-sign.sh
```

## **二、日常增量编译**

```
git switch --no-recurse-submodules custom/macos && \
git pull --ff-only --no-recurse-submodules origin custom/macos && \
git -C fcitx5-webview switch custom/macos && \
git -C fcitx5-webview pull --ff-only --no-recurse-submodules origin custom/macos && \
git submodule update --init --recursive -- \
    fcitx5 \
    fcitx5-beast \
    deps/AlertToast \
    deps/url-filter && \

./scripts/patch.sh && \
cmake --build build/$(uname -m) --parallel 8 && \

./scripts/code-sign.sh
```

## **三、更新策略**

| 操作         | 是否自动执行 |
| ---------- | ------ |
| 切换个人分支     | ✅      |
| 拉取个人仓库最新代码 | ✅      |
| 更新依赖子模块    | ✅      |
| 编译、安装、签名   | ✅      |
| 合并官方上游代码   | ❌      |
| 强制覆盖本地修改   | ❌      |
| 自动提交或推送    | ❌      |

这里的 `--ff-only` 很重要：如果本地与远程分支发生分歧，会停止操作，而不是擅自合并。

另外，如果 WebView 拉取了新提交，记得在测试通过后更新主项目中的子模块版本指针。

这样我们就将**同步上游、日常开发、编译安装**三个流程分离开了，平时直接执行增量编译命令即可。
